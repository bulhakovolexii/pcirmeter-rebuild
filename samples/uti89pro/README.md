# Зразки UNI-T UTi89 PRO (I-19)

Файли з камери кладіть сюди **як є** — копіюйте з карти/пам'яті всю теку цілком, з усіма файлами.
Знімки UTi89 PRO — **`.bmp`** по 231 013 Б; якщо камера пише ще й інші файли — їх теж. Не перезберігайте
й не редагуйте знімки — редактор зітре дані, дописані після зображення.

Уміст теки, крім цього README і `notes.csv`, **не потрапляє в git** (див. `.gitignore`).

## Які знімки потрібні

Перші 9 файлів (`Images/`) уже розібрано (`docs/spec/uti89pro.md`): у них **немає температурної карти** — лише
T max, T min (з координатами), T центру та сіре зображення для показу. Тому нові знімки — насамперед, щоб
з'ясувати, чи камера вміє більше.

1. ~~Меню збереження~~ — за посібником лише BMP; прошивка V0.2.
2. **Серія ε (3 файли, одна сцена зі штатива / на столі, нічого не рухати):** ε = 0,95 → 0,70 → 0,50.
   Записати показ центральної точки на екрані для кожного.
3. **Інші налаштування:** одиниці °F; курсор (центр / гаряча точка / ROI); інша палітра; температурна компенсація
   (наприклад, +5 °C) — по одному файлу тієї ж сцени, кожен раз змінюючи лише одне.
4. **Центральна точка на екрані** — вмикайте її показ: її значення зберігається у файлі й слугує еталоном.

## Нотатки до кожного файлу — `notes.csv`

Для кожного знімка запишіть те, що камера показувала на екрані (це наші еталони, поки немає ПК-програми UNI-T).
Порожні клітинки — нормально. Поле `comment` — що в кадрі та що змінено.
