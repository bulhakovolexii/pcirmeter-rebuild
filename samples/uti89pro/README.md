# Зразки UNI-T UTi89 PRO — гайд до серії знімків (I-19)

Уміст теки, крім цього README і `notes.csv`, **не потрапляє в git** (див. `.gitignore`).
`Images/` — перші 9 знімків викладача (уже розібрано, `docs/spec/uti89pro.md`).

## Навіщо

У файлі камери є лише T max, T min, T центру і кілька невідомих полів. Серія потрібна, щоб:
- підтвердити, що байт, де в усіх файлах 95, — це ε, і чи змінює ε записані температури;
- знайти, де у файлі одиниці °C/°F, режим курсора, палітра й температурна компенсація;
- мати еталони: значення з екрана камери проти значень, які прочитає застосунок.

## Підготовка

- Камера увімкнена 10–15 хв (посібник), не на зарядці.
- Сцена зі стабільною температурою і явним гарячим та холодним місцем: наприклад, чашка гарячої води (≈ 60–80 °C)
  на столі біля стіни. Чашку на час серії не доливати — охолоне на 1–2 °C, це нормально.
- Камера нерухомо: штатив або спертя на книжки. **Між кадрами серії не рухати.**
- Курсор: центральна точка увімкнена (її значення записується у файл), чашка — не в центрі кадру.
- Перед серією: ε 0,95, °C, палітра Iron Red, компенсація 0, автозбереження вимкнено.

## Що записати — `notes.csv`

Один рядок на знімок, з екрана камери **перед** натисканням спуску. Порожні клітинки — нормально.

| Колонка | Зміст |
|---|---|
| `file` | ім'я файлу (з камери, напр. `img20261024_101500.bmp`) |
| `n` | номер з таблиці вище |
| `emissivity` | ε у налаштуваннях |
| `units` | C або F |
| `cursor` | center / hot / roi |
| `palette` | назва палітри |
| `compensation` | температурна компенсація з налаштувань |
| `center` | показ центральної точки (у вибраних одиницях) |
| `max`, `min` | Max на екрані; верхнє й нижнє значення шкали |
| `comment` | що в кадрі, що пішло не так |

## Як передати

1. Камеру — у режим «USB disk», на Mac з'явиться диск «NO NAME».
2. Скопіювати нові `.bmp` у `samples/uti89pro/series-1/` **без змін** (не відкривати в редакторах і не перезберігати).
3. Заповнити `notes.csv` і сказати в сесії — далі `python3 -I tools/dump_uti.py samples/uti89pro/series-1/*.bmp`.
