# Зразки UNI-T UTi89 PRO (I-19)

Файли з камери кладіть сюди **як є** — копіюйте з карти/пам'яті всю теку цілком, з усіма файлами.
За аналізом ПК-програми UNI-T радіометричні знімки, найімовірніше, — **`.bmp`** (~400 КБ кожен); якщо камера
пише ще й `.jpg` чи інші файли — їх теж. Не перезберігайте й не редагуйте знімки —
будь-який редактор зітре радіометричні дані.

Уміст теки, крім цього README і `notes.csv`, **не потрапляє в git** (див. `.gitignore`).

## Які знімки потрібні

Мета — з'ясувати, що саме камера зберігає у файлі, і мати еталонні температури для звірки.
Знімайте зі штатива або спертим на стіл, щоб у серіях 2–4 кадр не зсувався.

1. **Звичайні сцени (5–10 файлів)** зі стандартними налаштуваннями (ε 0,95): чашка гарячої води, лід або
   холодна пляшка, радіатор, вікно, рука. Бажано, щоб у кадрі був і гарячий, і холодний об'єкт.
2. **Серія ε (3 файли, одна сцена, нічого не рухати):** ε = 0,95 → 0,70 → 0,50.
3. **Серія відбитої температури** (якщо камера її налаштовує): та сама сцена, T_відб = 20 → 50 °C.
4. **Серія палітр (2–3 файли, та сама сцена):** різні палітри (Iron, Rainbow, White hot…).
5. **Режими зображення**, які є в камері: лише ІЧ, суміщення з видимим (fusion / картинка-в-картинці), видиме фото.
6. **Діапазони вимірювання**, якщо перемикаються (наприклад, низький і високий), — по одному файлу.
7. Якщо є **ручна шкала** (фіксовані межі замість авто) — один файл із ручною шкалою.

Серії 2–4 найважливіші: якщо зміна ε/палітри не змінює даних у файлі — там сирі відліки, і температуру можна
перераховувати повністю; якщо змінює — там готові °C або лише картинка.

## Нотатки до кожного файлу — `notes.csv`

Для кожного знімка запишіть те, що камера показувала на екрані (це наші еталони, поки немає ПК-програми UNI-T).
Порожні клітинки — нормально. Поле `comment` — що в кадрі та що змінено.

Також допоможе: версія прошивки (меню «Про пристрій») і чи є в меню камери вибір формату збереження
(BMP / JPG, «радіометричний» знімок тощо) — якщо є, зняти по одному файлу кожного формату.
