**Ключові знахідки**
- Камера кафедри — CEM DT-980 (80×80). `.hir` = побайтова копія `.JPG`. Формат 2013 і 2021 р. один.
- Калібрувальна таблиця AD→T і всі параметри зйомки зберігаються в **кожному** файлі.
- Формула: LUT → поправка 0,95/0,05 → τ (таблиці пари/відстані) → рівняння Стефана–Больцмана з ε, T_відб, T_пов.
- Поля Max/Min у заголовку — межі автошкали камери; наш розрахунок збігається з ними в 26/26 файлах ≤ 0,11 °C.
- В оригіналі: числа показуються з 1 знаком; координат пікселів UI не показує; прямокутник не доходить
  до краю ближче ніж на 10 екранних px; середнє області в UI = середнє °C по екранних пікселях,
  а в `Rectangleobj` = °C від середнього AD (дві різні семантики — врахувати в I-11).
- `IrMeter.dll` імпортує також `FPGA_CalcTemp.dll`, якої немає в інсталяторі.

**Лишилось / відкрите**
- Еталони з оригіналу (I-08) — викладач заповнює бланк за гайдом.
- R-01: ΔAD із температури затвора, якщо поле 0x5C = 0.
