# Формат радіометричного файлу PCIRMeter / CEM (`*.jpg`, `*.hir`)

Статус: v1 (2026-10-22). Джерела: декомпіляція `IrMeter.dll` (`AnalyzeHead_ListVer.setbytes`,
`IR160struct`), Ghidra-аналіз `FPGA_CalcTemp_List.dll` (`FPGA_open` → `FUN_10001d40`, `FUN_10002470`),
перевірка на `samples/legacy-2013` (7 файлів) і `samples/latest-2021` (19 файлів, CEM DT-980).
Інструмент: `tools/dump_ir.py`.

Позначки: **[п]** — перевірено на всіх зразках, **[г]** — гіпотеза.

## Загальна структура

```
[ JPEG (EXIF/JFIF) … FFD9 ]  ← звичайне зображення, відкривається будь-яким переглядачем
[ File_Para_t      160 B ]  ← зсув T0
[ Type_Data_t × 16 256 B ]  ← таблиця блоків
[ блоки (видиме фото, ІЧ, аудіо, …) ]
[ uint32 LE T0 ]            ← останні 4 байти файлу
```

- Усі числа little-endian. **[п]**
- `.hir` і `.JPG` у зразках 2021 р. — побайтово ідентичні копії. **[п]**
- Головний JPEG: 640×480 (2013) або 1280×960 (DT-980); у DT-980 є APP2 з вкладеним JPEG (мініатюра) **[г]**.

## File_Para_t (зсув T0, 160 байт) [п]

| Зсув | Тип | Поле | Приклад |
|---|---|---|---|
| 0x00 | char[8] | Flag / модель | `DT-980` |
| 0x08 | int32 | Length (= 160) | |
| 0x0C | char[16] | Producer | `CEM` |
| 0x1C | char[16] | Дата калібрування | `2017-04-06` |
| 0x2C | char[16] | Серійний номер | `170409786` |
| 0x3C | char[16] | Версія ПЗ камери | `3.0.5` |
| 0x4C | char[16] | Час зйомки `YYYYMMDDhhmmss` | `20210212125856` |
| 0x5C | int16×2 | Розмір зображення | 1280×960 |
| 0x60 | int16×2 | Розмір «додаткового» зображення | 1280×960 |
| 0x64 | int16×2 | Розмір ІЧ-сенсора W×H | 80×80, 160×120, 384×288 |
| 0x68 | int16 | File_Type (3 → видиме фото = головний JPEG) | 1 |
| 0x6A | int16 | TypeNum (кількість блоків?) | 2 |
| 0x6C | 52 B | резерв | |

Рядки ASCII, доповнені `\0`; байт `0xFF` у кінці деяких полів — роздільник, ігнорувати.

## Type_Data_t × 16 (зсув T0+0xA0, по 16 байт) [п]

`int32 type, int32 pointer (абсолютний зсув у файлі), int32 length, int32 reserved`.
Порожні записи мають `length = 0`.

| type | Вміст |
|---|---|
| 0 | ІЧ-блок (див. нижче) **[п]** |
| 1 | Аудіо (голосова нотатка), формат **[г: WAV]** — у зразках відсутнє |
| 3 | Текст користувача (ASCII) |
| 4 | Видиме фото (JPEG) **[п]** |
| 6 | Користувацькі дані (позначки/об'єкти програми) |

## ІЧ-блок (type 0)

```
[ заголовок 0x700 (1792) байт ][ uint16 AD[W×H], рядок за рядком ][ 1024 B — лише у файлах 2013 р. [г: палітра] ]
```

Піксель (x, y) → `AD[y·W + x]`. **[п]**

### Заголовок ІЧ-блоку (поля, що потрібні для температури) [п]

Кодування температур: `T = u16 / 10 − 100` (°C).

| Зсув | Тип | Поле | Кодування |
|---|---|---|---|
| 0x00 | 16 B | Spot (прапорці точок) | |
| 0x10 | 16 B | Area | |
| 0x20 | 2 B | Line | |
| 0x25 | u8 | ε — коефіцієнт випромінювання | /100 |
| 0x26 | u16 | Відстань, м | як є |
| 0x28 | u16 | Температура повітря | /10 − 100 |
| 0x2A | u8 | Відносна вологість | /100 |
| 0x2C | u16 | Відбита температура | /10 − 100 |
| 0x2E | u16 | Зсув (offset) | /10 − 100 |
| 0x30 | u16 | Level (рівень відображення) | /10 − 100 **[г]** |
| 0x32 | u16 | Span | **[г]** |
| 0x34 | u16 | Max_Temp — верхня межа автошкали = T(FPGA_Level+FPGA_Span), **не** максимум кадру | /10 − 100 |
| 0x36 | u16 | Min_Temp — нижня межа автошкали = T(FPGA_Level) | /10 − 100 |
| 0x38 | u16 | Camera_Lens | |
| 0x3A | u8 | Temp_Range: 0 → −20…150 °C, 1 → 0…400 °C | |
| 0x3B–0x4F | | ізотерми, тривога, палітра | **[г]** |
| 0x50 | u16 | FPGA_Level (AD) — автоматичний рівень | |
| 0x52 | u16 | FPGA_Span (AD) | |
| 0x54 | u16 | Температура затвора / сенсора 1 | /10 − 100 |
| 0x56, 0x58 | u16 | Сенсори 2, 3 | |
| 0x5C | u16 | ΔAD затвора: `u16 − 10000`, 0 = відсутнє | |
| 0x600 | u16 | N — кількість точок калібрувальної таблиці (≤ 60) | |
| 0x604 | u16[60] | AD-вузли таблиці (зростають) | |
| 0x680 | i16[60] | Температури вузлів, °C (крок 10 °C, від −30) | |

Решта заголовка (вимірювальні об'єкти `IR_Para`: 16 точок, 16 областей, 2 лінії) —
структури `Spot_Para`/`Area_Para`/`Line_Para`, див. TODO.
