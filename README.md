# pcirmeter-rebuild

Кросплатформний вебзастосунок для відкриття та аналізу радіометричних термограм, сумісний із файлами
програми PCIRMeter (тепловізори CEM DT-980 та подібні). Працює повністю в браузері, без сервера.
Створюється для навчання студентів (енергоменеджмент, основи термографії, НТУ «ХПІ»).

**Стан:** у розробці. План — [`docs/PLAN.md`](docs/PLAN.md), журнал — [`docs/PROGRESS.md`](docs/PROGRESS.md),
специфікації формату й алгоритму температури — [`docs/spec/`](docs/spec/).

## Розробка

Потрібен Node.js 22.

```bash
npm ci
npm run dev     # dev-сервер
npm test        # тести (Vitest)
npm run lint    # ESLint + Prettier
npm run build   # перевірка типів + збірка в dist/
```

## Правовий статус

Це незалежна реалізація з нуля. Формат файлів і формули описано у специфікаціях для забезпечення сумісності
(ст. 6 Директиви 2009/24/ЄС); код, бінарні файли та ресурси оригінальної програми в репозиторій не входять.
